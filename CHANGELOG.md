# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-08-31

### Added

- Initial release of MovieEvents Blazor WebAssembly PWA
- Movie search and favourites using TMDb API
- Friends and groups management
- Location management
- Movie event scheduling with Google Calendar integration
- Email invitations and cancellations via Gmail API
- Dark/light mode theme toggle
- Data export/import as JSON
- Gmail backup functionality
- Progressive Web App with offline support
- Service Worker with caching
- Responsive Bootstrap UI with icons
- GitHub Actions CI/CD pipeline
- Automatic deployment to GitHub Pages
- Comprehensive unit tests with xUnit, FluentAssertions, and NSubstitute
- Full documentation suite (README, Architecture, Deployment, Google API, TMDb, Testing)
